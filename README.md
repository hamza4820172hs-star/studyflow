# StudyFlow Android

مشروع Android حقيقي يبني APK من خلال GitHub Actions.

## طريقة البناء
1. ارفع محتويات هذا المجلد إلى جذر مستودع GitHub (لا ترفع مجلد StudyFlow_Android كطبقة إضافية).
2. افتح تبويب Actions.
3. اختر `Build StudyFlow APK` ثم `Run workflow`، أو انتظر البناء التلقائي بعد push إلى main.
4. افتح عملية البناء الناجحة، وانزل إلى Artifacts.
5. حمّل `StudyFlow-debug-apk.zip` وفك ضغطه لتحصل على `app-debug.apk` وثبّته على هاتف Android.

## ملاحظات
- الواجهة محفوظة داخل التطبيق؛ لا يحتاج التطبيق إلى استضافة أو اتصال إنترنت لفتح الصفحات والوظائف الأساسية.
- بيانات المهام والجدول وجلسات المذاكرة تحفظ محليًا داخل التطبيق.
- هذا إصدار Debug للتجربة. لا تنشره كتطبيق عام قبل تجهيز توقيع Release.
- ملف PWA الأصلي جرى تضمينه كواجهة محلية داخل WebView، مع الاحتفاظ بتصميمه ووظائفه.
